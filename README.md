# Entrega-Final-Coderhouse
triage automático de pedidos de cotización para un productor asesor de seguros generales. Un cliente pide una cotización; la IA interpreta el pedido, extrae los datos, detecta lo que falta, asigna una prioridad y redacta la respuesta. El productor aprueba o rechaza con un clic y recién ahí se contacta al cliente.

## Enlances de Entrega 
1. Video Demo (3 min)
2. Dashboard de control (KPIs)
3. Base de datos (solo lectura)
4. Flujo Principal (JSON)
5. Workflow de manejo de errores(JSON)
6. Esquema JSON de Integracion
7. Capturas de Evidencia
